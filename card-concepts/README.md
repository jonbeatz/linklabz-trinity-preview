# LinkLabz Card Concepts

Static export of the Muse web artifact `linklabz-card-concepts` ("LinkLabz Card Concepts").

## What it is

Concept demos of the 19 LinkLabz review cards in two alternative card layouts:

- **Card Swap** — stacked deck; the active/top card cycles to the back of the deck (based on godui.design Card Swap).
- **Cover Flow** — 3D carousel; centered forward-facing card with angled, recessed neighboring cards (based on godui.design Cover Flow).

**Dark mode is the default.** Also includes section navigation, a back-to-top control,
a project overview write-up, per-layout "best use" notes, a verdict reference key,
and help lightboxes explaining the system and each layout.

## Notes

- Self-contained single HTML file (`index.html`) — no build step, no backend.
- Exported from the finished Muse artifact on 2026-09-23; it does not auto-update with later artifact edits.
- Not live on GitHub Pages until the `card-concepts` branch is merged to `main`
  (Pages serves `main`; once merged the page lives at `/card-concepts/`).
